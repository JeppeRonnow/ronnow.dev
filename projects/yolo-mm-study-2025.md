# YOLO M&M Detection Study

**Technologies:** YOLOv11, OpenCV, Python, Roboflow, Machine Learning

Comparing classical computer vision (OpenCV) and modern ML (YOLOv11) for detecting M&Ms on plates.

![[img/yolo_output.jpg]]

## About

This project revisits a 2nd semester OpenCV project to compare traditional CV methods with ML.

In my earlier robotics project, we used classical computer vision techniques with OpenCV for color segmentation and contour detection to identify M&Ms. This follow-up study explores how modern deep learning approaches compare to traditional methods.

- **OpenCV Approach**: Color segmentation in HSV space and contour detection for object identification
- **YOLOv11 Approach**: State-of-the-art deep learning object detection model

The goal is to quantify the performance differences between classical computer vision and modern machine learning for this specific detection task, measuring accuracy, speed, and robustness under varying lighting conditions.

## Dataset
- 644 images of M&Ms on plates
- Annotated using Roboflow
- Training set: ~200 images
- Multiple lighting conditions and candy arrangements
